# Unemployment Analysis

This project analyzes unemployment trends in India using Python and data visualization.

## Overview

The project uses unemployment data from **May 2019 to June 2020** to study unemployment rates, employment levels, labour participation, regional differences, and the impact of COVID-19.

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Monthly unemployment trends
* State-wise analysis
* Rural vs Urban comparison
* Pre-COVID vs COVID analysis
* Data visualization
* Correlation analysis

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Installation

```bash
git clone https://github.com/your-username/Unemployment-Analysis.git
cd Unemployment-Analysis
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook
```

Then open **`Unemplyment_Analysis.ipynb`** and run the cells.

## Methodology

The notebook cleans the dataset, converts dates, removes empty records, performs EDA, analyzes monthly and regional trends, compares Rural and Urban areas, and studies the COVID-19 period.

## Key Findings

* Average unemployment increased from **9.51% to 17.77%** during the COVID period.
* Average employment decreased from **400.18M to 332.38M**.
* Labour participation decreased from **43.89% to 39.33%**.
* The highest unemployment rate occurred in **May 2020 at 24.88%**.
